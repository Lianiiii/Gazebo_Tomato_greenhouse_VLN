# 仿真场景自定义（YAML 驱动）

## 能做什么

- **改 metal 长度**：按 soilbed 数量自动贴合，或手动指定米数
- **增加 / 复制整行种植带**：在 YAML 里复制一个 `rows` 条目并改 `x`
- **保存为新场景**：写入 `worlds/<scene_name>/`，**不覆盖**原始 `2mx3m`
- **切换场景启动**：不改 `./run_tomato_bot_test.sh`，用 launch 的 `world:=` 或 `run_tomato_scene`

## 为什么原 metal 很长

`metal_*.dae` 长轴（mesh X）跨度约 `0→1000`，`model.sdf` 里是：

```xml
<scale>0.015 0.015 0.015</scale>
```

→ 视觉长度约 **15 m**。Gazebo GUI 移动/复制改不了这个 scale，需要改（副本的）`model.sdf`。

本工具会**复制**一份新的 `metal_<id>`，只改新模型的各向异性 scale：

`scale_x = 目标长度(m) / 1000`，`scale_y = scale_z = 0.015`。

## 快速开始

### 1. 看样例并生成

样例配置：

[`src/aoc_tomato_farm/tomato_farm_simulator/config/scenes/short_metal_demo.yaml`](../src/aoc_tomato_farm/tomato_farm_simulator/config/scenes/short_metal_demo.yaml)

```bash
# 仅预览计算（不写文件）
/home/ylubt2204/bin/tomato_scene_gen short_metal_demo --dry-run

# 真正生成（写入 src + 同步到 install）
/home/ylubt2204/bin/tomato_scene_gen short_metal_demo
```

生成物：

- `.../tomato_farm_simulator/worlds/short_metal_demo/tomato_farm_short_metal_demo_gazebo_classic.world`
- `.../tomato_farm_simulator/models/metal_<新id>/`（新缩放 metal）
- 同步到 `install/tomato_farm_simulator/share/...` 对应路径

### 2. 启动新场景

**方式 A（推荐包装脚本）：**

```bash
/home/ylubt2204/bin/run_tomato_scene short_metal_demo
```

**方式 B（直接 ros2 launch，不改 run_tomato_bot_test.sh）：**

```bash
source /opt/ros/humble/setup.bash
source /home/ylubt2204/tomato_ws/install/setup.bash
export RMW_IMPLEMENTATION=rmw_fastrtps_cpp
export GAZEBO_MODEL_PATH=/home/ylubt2204/tomato_ws/install/tomato_farm_simulator/share/tomato_farm_simulator/models:${GAZEBO_MODEL_PATH:-}

ros2 launch tomato_farm_simulator tomato_farm_world.launch.py \
  world:=/home/ylubt2204/tomato_ws/install/tomato_farm_simulator/share/tomato_farm_simulator/worlds/short_metal_demo/tomato_farm_short_metal_demo_gazebo_classic.world
```

`./run_tomato_bot_test.sh` 仍启动**原始** `2mx3m`，行为不变。

## YAML 字段说明

| 字段 | 含义 |
|---|---|
| `scene_name` | 新场景名；禁止 `2mx3m` / `4mx4m` |
| `include_structure` | 是否放入 `structure_0` 大棚骨架 |
| `model_pool.*` | `auto` 或模型名列表；复用现有 tomato/soilbed/…，不跑 Blender |
| `metal.template` | 复制哪个 metal（默认 `metal_601394`） |
| `metal.mesh_length_units` | dae 长轴单位长度（默认 1000） |
| `metal.cross_scale` | Y/Z 粗细 scale（默认 0.015） |
| `rows[].x` / `y0` | 行位置；`y0` 为第一个 soilbed 的 y |
| `rows[].crop_count` / `crop_dist` | 株数与间距 |
| `rows[].metal_length_m` | 手动长度（米）；非 null 时优先 |
| `rows[].fit_to_crops` | 为 true 且未给长度时：`(n-1)*dist + length_padding_m` |
| `rows[].length_padding_m` | 自动长度两端余量（默认 0.8） |

### 复制一整行

把某个 `rows` 条目整段复制，改 `name` 和 `x`（行间距）即可，例如再加一行 `x: 8.0`。

### 缩短 metal 到贴合 soilbed

```yaml
crop_count: 3
crop_dist: 1.0
metal_length_m: null
fit_to_crops: true
length_padding_m: 0.8   # → 长度 2.8 m
```

或直接：

```yaml
metal_length_m: 2.8
fit_to_crops: false
```

## 工具命令

```bash
/home/ylubt2204/bin/tomato_scene_gen --list-pool
/home/ylubt2204/bin/tomato_scene_gen my_scene.yaml --dry-run
/home/ylubt2204/bin/tomato_scene_gen my_scene.yaml
/home/ylubt2204/bin/tomato_scene_gen my_scene.yaml --force   # 覆盖同名新场景
/home/ylubt2204/bin/run_tomato_scene <scene_name>
```

也可把 YAML 放在任意路径，或只写场景名（自动找 `config/scenes/<名>.yaml`）。

## 限制（按需求）

- **不修改**原始 `worlds/2mx3m/**`、已有 `models/*` 内容、`tomato_farm_world.launch.py`、`run_tomato_bot_test.sh`
- 新 metal 是**新目录**；tomato/soilbed 等只是在 world 里再次 `include` 复用
- install 非 symlink：生成脚本会自动把新 world/metal 同步进 `install/.../share/`；若你只改了 YAML 后手动改文件，记得再跑一次生成或自行拷贝

## 验收建议

1. 生成前后对比：`metal_601394/model.sdf` 与 `worlds/2mx3m/...world` 无变化
2. 新 metal 的 `<scale>` 约为 `0.0028 0.015 0.015`（2.8m 时）
3. `run_tomato_scene short_metal_demo` 中目视 metal 与 3 个 soilbed 齐长
4. `./run_tomato_bot_test.sh` 仍为原大棚
