# 使用方法（TomatoBot 最小可用仿真）

## 环境准备

```bash
cd /home/ylubt2204/tomato_ws
source /opt/ros/humble/setup.bash
colcon build --symlink-install --packages-select tomato_bot_description tomato_bot_controller tomato_farm_simulator
source install/setup.bash
```

建议在 WSL 下固定 FastDDS（避免 CycloneDDS participant 耗尽导致 spawn 失败）：

```bash
export RMW_IMPLEMENTATION=rmw_fastrtps_cpp
```

`./run_tomato_bot_test.sh` / `./start_individual.sh` 已默认设置该项。

如有残留 Gazebo 进程，先清理：

```bash
pkill -9 gzserver gzclient || true
```

## 推荐：一键启动

```bash
./run_tomato_bot_test.sh
```

该脚本会：
1. 启动番茄大棚 Gazebo 世界
2. 自动生成 TomatoBot（只 spawn 一次）
3. 启动键盘控制（`/cmd_vel`）
4. 启动 RViz（RGB/Depth/RobotModel）

## 分步启动

```bash
# 1) 大棚 + TomatoBot（已包含 spawn，不要再二次 spawn）
./start_individual.sh gazebo

# 2) 另开终端：键盘控制
./start_individual.sh keyboard

# 3) 可选：RViz
rviz2 -d src/tomato_bot_controller/config/tomato_bot_rviz.rviz
```

仅在你用 `spawn_robot:=false` 启动世界时，才需要单独 spawn：

```bash
ros2 launch tomato_farm_simulator tomato_farm_world.launch.py spawn_robot:=false
./start_individual.sh spawn
```

## 控制说明

差速轮，**没有侧移**：

- `W`：前进
- `S`：后退
- `A` / `Q`：左转
- `D` / `E`：右转
- 空格：停止
- `ESC`：退出键盘节点

也可直接发速度指令：

```bash
ros2 topic pub /cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.2}, angular: {z: 0.0}}" -r 10
```

## 关键话题

| 话题 | 类型 | 说明 |
|---|---|---|
| `/cmd_vel` | `geometry_msgs/Twist` | 速度指令输入 |
| `/odom` | `nav_msgs/Odometry` | 里程计 |
| `/camera/color/image_raw` | `sensor_msgs/Image` | RGB |
| `/camera/depth/image_raw` | `sensor_msgs/Image` | Depth |
| `/camera/color/camera_info` | `sensor_msgs/CameraInfo` | RGB 内参 |
| `/camera/depth/camera_info` | `sensor_msgs/CameraInfo` | Depth 内参 |
| `/camera/points` | `sensor_msgs/PointCloud2` | 点云（可选） |

相机高度约 **0.7 m**。

## 验收检查

```bash
ros2 topic list | rg 'cmd_vel|camera|odom'
ros2 topic echo /camera/color/image_raw --once
ros2 topic echo /camera/depth/image_raw --once
```

成功标准：Gazebo 可见大棚与 Bot；`/cmd_vel` 或键盘可使 Bot 移动；RViz 能看到 RGB/Depth。
